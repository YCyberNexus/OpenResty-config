# 知识库接口文档

> 来源：用户于 2026-07-26 提供的《知识库接口文档.md》。本副本用于规则溯源；其中未写明的 Host、IP、端口、身份、上限和错误结构不得自行推断。

## 1. 健康检查

```http
GET /ai/knowledge/health
```

成功响应：

```json
{
  "status": "ok",
  "database": "ok",
  "active_assets": 25,
  "total_assets": 28,
  "embedding_model": "BAAI/bge-base-zh-v1.5",
  "embedding_dim": 768
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `status` | string | API 状态 |
| `database` | string | PostgreSQL 连接状态 |
| `active_assets` | integer | 已激活版本的文档数 |
| `total_assets` | integer | 文档资产总数 |
| `embedding_model` | string | 当前 Embedding 模型 |
| `embedding_dim` | integer | 向量维度 |

## 2. 知识库向量检索

```http
POST /ai/knowledge/search
Content-Type: application/json
```

请求体：

```json
{
  "query": "机台发生通信异常时应该如何处理？",
  "top_k": 5
}
```

| 字段 | 类型 | 必填 | 限制 | 说明 |
|---|---|---:|---|---|
| `query` | string | 是 | 1～4000 字符 | 检索问题 |
| `top_k` | integer | 否 | 1～50，默认 5 | 返回 Chunk 数量 |

成功响应：

```json
{
  "query": "机台发生通信异常时应该如何处理？",
  "top_k": 5,
  "retrieval_mode": "pgvector_active_versions_only",
  "embedding_model": "BAAI/bge-base-zh-v1.5",
  "results": [
    {
      "asset_id": "f440c18e-a281-44bc-a878-8aa92b620879",
      "asset_key": "equipment/ASML_manual.pdf",
      "asset_name": "ASML_manual.pdf",
      "version_id": "e8b85a47-9b58-49d0-8711-17de3df5ea87",
      "version_no": 2,
      "chunk_id": 10235,
      "chunk_index": 36,
      "content": "发生通信异常后，首先检查设备网络连接状态……",
      "page_number": 18,
      "section_title": "通信异常处理",
      "metadata": {
        "source": "/source_docs/equipment/ASML_manual.pdf",
        "page": 17
      },
      "distance": 0.1847,
      "vector_score": 0.8153
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `query` | string | 实际使用的查询内容，已去除首尾空格 |
| `top_k` | integer | 请求的最大结果数 |
| `retrieval_mode` | string | 当前固定为仅检索激活版本 |
| `embedding_model` | string | 查询向量使用的模型 |
| `results` | array | 按向量距离从小到大排列的 Chunk |

结果字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `asset_id` | string | 文档资产 UUID |
| `asset_key` | string | 相对 `source_docs` 的文件路径 |
| `asset_name` | string | 文件名 |
| `version_id` | string | 当前激活版本 UUID |
| `version_no` | integer | 文档版本号 |
| `chunk_id` | integer | Chunk 数据库 ID |
| `chunk_index` | integer | Chunk 在文档中的顺序，从 0 开始 |
| `content` | string | Chunk 完整文本 |
| `page_number` | integer/null | 页码，PDF 通常从 1 开始 |
| `section_title` | string/null | 章节标题，解析不到时为 null |
| `metadata` | object | Loader 生成的原始元数据 |
| `distance` | number | pgvector 余弦距离，越小越相似 |
| `vector_score` | number | `1 - distance`，越大越相似 |

错误码：

| HTTP 状态码 | 场景 |
|---:|---|
| `200` | 请求成功 |
| `422` | `query` 为空、过长，或 `top_k` 不在 1～50 |
| `502` | Embedding 服务连接、返回值或向量维度异常 |
| `503` | PostgreSQL 连接失败或向量检索失败 |

错误响应：

```json
{
  "detail": "Embedding服务调用失败"
}
```
