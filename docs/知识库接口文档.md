# 知识库接口文档

> 来源：用户于 2026-08-04 提供的《知识库相关接口.txt》。本副本用于规则溯源；
> 其中未写明的 Host、IP、端口、身份、错误状态码和大小上限不得自行推断。

## 1. 黄区 API 总表

| 接口 | 方法 | 调用方 | 职责 |
|---|---|---|---|
| `/ai/knowledge/search` | POST | 蓝区 Skill / 普通业务系统 | 查询 pgvector 当前生效 chunk，只返回向量结果 |
| `/ai/knowledge/assets/{asset_id}` | GET | 蓝区 Skill / 普通业务系统 | 查询资产详情、当前版本、raw document、chunk 统计 |
| `/ai/knowledge/health` | GET | 运维 / Skill | 检查 PostgreSQL、资产数量、模型配置 |
| `/ai/knowledge/graph/query` | POST | 蓝区 Skill | 执行受控只读 Cypher，返回图谱结果 |
| `/ai/knowledge/graph/health` | GET | 运维 / Skill | 检查 Neo4j 连接状态 |

## 2. Retrieval API：知识库主检索

```http
POST /ai/knowledge/search
Content-Type: application/json
```

请求字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `query` | string | 是 | 用户原始问题或 Skill 改写后的向量检索 query，长度 1～4000 |
| `top_k` | integer | 否 | 默认 5，建议范围 1～50 |

```json
{
  "query": "ASML 通信异常怎么排查",
  "top_k": 5
}
```

响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `query` | string | 本次实际检索使用的 query |
| `top_k` | integer | 向量检索返回数量 |
| `retrieval_mode` | string | 固定为 `pgvector_active_versions_only` |
| `embedding_model` | string | 当前使用的 embedding 模型 |
| `results` | array | 向量检索结果列表 |

`results` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `asset_id` | string | 资产 ID，对应 `kb_assets.id` |
| `asset_key` | string | 资产路径型 key |
| `asset_name` | string | 资产文件名 |
| `version_id` | string | 当前生效版本 ID |
| `version_no` | integer | 当前生效版本号 |
| `chunk_id` | integer | 命中的 chunk ID |
| `chunk_index` | integer | 文档内 chunk 序号 |
| `content` | string | 命中的 chunk 文本内容 |
| `page_number` | integer/null | 页码；无法识别时为 null |
| `section_title` | string/null | 章节标题；没有时为 null |
| `metadata` | object | chunk 元数据，例如 `source_path`、`loader`、`page` 等 |
| `distance` | number | pgvector 距离，越小越相似 |
| `vector_score` | number | 当前为 `1 - distance` |

```json
{
  "query": "ASML 通信异常怎么排查",
  "top_k": 5,
  "retrieval_mode": "pgvector_active_versions_only",
  "embedding_model": "BAAI/bge-base-zh-v1.5",
  "results": [
    {
      "asset_id": "f440c18e-a281-44bc-a878-8aa92b620879",
      "asset_key": "unclassified/ASML_XT-1060K_SECS_manual_51146.pdf",
      "asset_name": "ASML_XT-1060K_SECS_manual_51146.pdf",
      "version_id": "e8b85a47-9b58-49d0-8711-17de3df5ea87",
      "version_no": 2,
      "chunk_id": 123,
      "chunk_index": 15,
      "content": "命中的 chunk 文本内容",
      "page_number": 12,
      "section_title": "章节标题",
      "metadata": {},
      "distance": 0.18,
      "vector_score": 0.82
    }
  ]
}
```

## 3. Asset API：资产详情查询

```http
GET /ai/knowledge/assets/{asset_id}
```

`asset_id` 是必填路径参数，对应 `kb_assets.id`。当前 WAF 将该参数限制为规范 UUID，
不使用任意路径正则。

顶层响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `request_id` | string | 请求 ID |
| `asset_id` | string | 资产 ID |
| `asset_key` | string | 资产 key |
| `asset_name` | string | 资产名称 |
| `current_version_id` | string/null | 当前生效版本 ID |
| `current_version` | object/null | 当前生效版本摘要 |
| `raw_document` | object/null | 当前版本原文摘要 |
| `chunk_summary` | object/null | 当前版本 chunk 汇总 |
| `versions` | array | 该资产所有版本列表 |
| `created_at` | datetime | 资产创建时间 |
| `updated_at` | datetime | 资产更新时间 |

`current_version` / `versions` 字段：

| 字段 | 类型 |
|---|---|
| `version_id` | string |
| `version_no` | integer |
| `source_checksum` | string |
| `source_path` | string |
| `parser_version` | string |
| `splitter_version` | string |
| `embedding_model` | string |
| `embedding_dim` | integer |
| `expected_chunk_count` | integer/null |
| `persisted_chunk_count` | integer |
| `embedded_chunk_count` | integer |
| `status` | string |
| `dagster_run_id` | string/null |
| `error_stage` | string/null |
| `error_message` | string/null |
| `created_at` | datetime |
| `completed_at` | datetime/null |
| `is_current` | boolean |

`raw_document` 字段：

| 字段 | 类型 |
|---|---|
| `raw_document_id` | string |
| `content_length` | integer |
| `metadata` | object |
| `created_at` | datetime |

`chunk_summary` 字段：

| 字段 | 类型 |
|---|---|
| `total_chunk_count` | integer |
| `embedded_chunk_count` | integer |
| `pending_chunk_count` | integer |
| `failed_chunk_count` | integer |
| `first_chunk_id` | integer/null |
| `last_chunk_id` | integer/null |


| 响应字段 | 类型 | 说明 |
|---|---|---|

## 5. Neo4j Query API：只读图谱查询

```http
POST /ai/knowledge/graph/query
Content-Type: application/json
```

普通前端不建议直接调用。

| 请求字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `cypher` | string | 是 | 只读 Cypher，长度 1～20000 |
| `parameters` | object | 否 | 默认 `{}` |
| `limit` | integer | 否 | 默认 100，建议范围 1～1000 |

```json
{
  "cypher": "MATCH (e) WHERE toLower(e.name) CONTAINS toLower($entity) RETURN e LIMIT $limit",
  "parameters": {
    "entity": "ASML",
    "limit": 10
  },
  "limit": 10
}
```

| 响应字段 | 类型 | 说明 |
|---|---|---|
| `request_id` | string | 图谱查询请求 ID |
| `cypher` | string | 实际执行的规范化 Cypher |
| `parameters` | object | 实际查询参数 |
| `limit` | integer | 接口层返回限制 |
| `elapsed_ms` | number | 查询耗时，毫秒 |
| `columns` | array | 返回列名 |
| `row_count` | integer | 返回行数 |
| `rows` | array | JSON 安全化后的查询结果行 |

```json
{
  "request_id": "4a95f9c2-b8e7-4d1c-9d76-1ac79cbdcf8a",
  "cypher": "MATCH (e) WHERE ... RETURN e LIMIT $limit",
  "parameters": {"entity": "ASML", "limit": 10},
  "limit": 10,
  "elapsed_ms": 12.3,
  "columns": ["e"],
  "row_count": 1,
  "rows": [
    {
      "e": {
        "element_id": "neo4j-element-id",
        "labels": ["Equipment"],
        "properties": {"name": "ASML XT-1060K"}
      }
    }
  ]
}
```

## 7. 当前 WAF 映射说明

- 活动 Host 为 `kb.pxsemic.tech`，五个接口均走现有蓝 WAF、黄 WAF和固定黄区后端。
- `/assets/{asset_id}` 使用 V2 命名路径参数，并为 `asset_id` 配置 UUID schema。
- `/search` 的 `query` 必填；`include_graph`、`graph_top_k` 和 `graph_results` 不属于该接口。
- `/graph/query` 除 JSON schema 外还启用 `cypher_read_only_v1`；写入/管理关键字、`CALL`、
  多语句和无法安全解析的语句会被 WAF 拒绝，后端 Neo4j 账号仍必须保持只读。
- 文档未登记四个新增接口的错误状态码和错误响应结构，因此当前只放行其 `200` 响应；
  未登记状态码由 WAF fail-closed 为 `502`。
- `metadata`、Cypher `parameters` 和图谱 `rows` 是文档明确的动态对象，当前规则允许其扩展字段，
  规则检查会输出对应安全偏离 warning；五接口均为 buffered，响应总大小受 1 MiB 上限约束。
- 图谱查询请求为支持最长 20000 个 UTF-8 字符，该接口请求 JSON 上限为 128 KiB；V2 buffered
  请求全局技术上限为 1 MiB。
- 活动知识库规则不记录请求/响应正文原文，只记录大小和 SHA-256，避免在审计日志复制黄区内容。
